# FASSA Web - Starter Template

This is a starter template application for the FASSA monorepo.

## Getting Started

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

## Port Configuration

This application runs on port 3001 by default. You can override this by setting the `PORT` environment variable:

```bash
PORT=3002 pnpm dev
```
